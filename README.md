# MoodTunes

An engaging web app that generates personalized music playlists based on your daily mood and activities. Simply select your current mood, activity, and preferred genres, and MoodTunes will create the perfect playlist using AI.

Key Features:
- Interactive mood selection wheel
- Activity context picker
- Genre preference toggles
- Playlist generation with song previews
- Daily mood tracking visualization
- Social sharing

Tech Stack:
- HTML5, CSS3, JavaScript
- Web Audio API
- Local Storage for preferences
- Responsive design for all devices
